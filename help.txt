| Package         | Purpose                                         |
| --------------- | ----------------------------------------------- |
| `mcp`           | Build the MCP Server, tools, resources, prompts |
| `httpx`         | Call your .NET, Java, and Python APIs           |
| `python-dotenv` | Read configuration from `.env`                  |
| `sqlalchemy`    | SQL Server database access                      |
| `pyodbc`        | SQL Server ODBC driver integration              |
| `pymongo`       | MongoDB access                                  |
| `pandas`        | Convenient CSV reading/writing                  |
| `pydantic`      | Request/response validation and models          |
